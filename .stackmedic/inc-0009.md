# StackMedic Fix Notes: INC-0009

**Fix Type:** CODE
**Service:** BackgroundWorker
**Severity:** CRITICAL

## Root Cause
The BackgroundWorker processes order reconciliations while the stock commit has not yet been finalized. Payments are accepted for orders in a non‑payable state, causing RECON_STATE_MISMATCH and UNEXPECTED_PAYMENT_STATE errors.

## Recommended Fix
Add a validation check that the stock commit is finalized before accepting payment; if not, reject the payment and trigger a retry or manual intervention.

## Reason
Enforcing the required ordering prevents payments from being recorded when the inventory state is still pending, resolving the inconsistency.
