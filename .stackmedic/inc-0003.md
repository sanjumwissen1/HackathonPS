# StackMedic Fix Notes: INC-0003

**Fix Type:** CONFIG
**Service:** InventoryService
**Severity:** HIGH

## Root Cause
The store service is intermittently unavailable (STORE_TIMEOUT events), causing reservation operations in InventoryService to time out and leave reservations incomplete.

## Recommended Fix
Increase the store service timeout from its default value to a higher threshold (e.g., 60 seconds) so that pending reservation operations can complete before being aborted by a timeout.

## Reason
Higher timeout allows the store service to finish processing reservations, preventing premature aborts and completing the reservation flow.
