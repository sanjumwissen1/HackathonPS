# StackMedic Fix Notes: INC-0003

**Fix Type:** CONFIG
**Service:** OrderService
**Severity:** HIGH

## Root Cause
Transient inventory store failures caused reservation phase failures, leading to order pipeline aborts.

## Recommended Fix
Edit /etc/order-service/config.yaml to set inventory_reserve_timeout=10s and enable retry with max_attempts=3; redeploy configuration.

## Reason
Increasing the reservation timeout and adding retries will allow the order service to recover from brief inventory store outages, preventing reservation phase failures.
