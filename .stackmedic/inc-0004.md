# StackMedic Fix Notes: INC-0004

**Fix Type:** CODE
**Service:** OrderService
**Severity:** CRITICAL

## Root Cause
Reservation finalisation fails causing the OrderService to remain in CREATED state with a timeout, resulting in STATE_UNRESOLVED errors.

## Recommended Fix
Add retry logic for reservation finalisation and update the order state only after a successful reservation completes.

## Reason
The fix ensures that the reservation is fully completed before any state change, eliminating the timeout and leaving orders in an unresolved state.
